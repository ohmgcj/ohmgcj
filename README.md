### Hi, I'm Caio 👋

Mobile developer from São Paulo, Brazil, building with **React Native, Expo and TypeScript** — and expanding to the web with **React and Next.js**.

- 📱 Built the mobile app for **Lolla**, an AI assistant: screens from the design, Expo Router navigation, REST API integration and the chat interface with file attachments.
- 🔧 Built **AutoParts Insight**, a full-stack tool (Next.js, NestJS, PostgreSQL, Prisma, Docker) used in a real product-development workflow to cross-reference auto part codes and compare catalogs. *(Private — public demo coming soon.)*
- 🎨 Background in Graphic Design — I care about turning designs into faithful, consistent interfaces.
